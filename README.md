Arduino Nano-Based Multi-Sensor Home Safety Monitoring System

Overview

SafeNest is an Arduino Nano-based home safety monitoring system developed and tested using the Wokwi simulation environment. The system monitors gas, temperature, motion, and water-level conditions and provides visual and audible alerts based on predefined thresholds and conditions.

Components

- Arduino Nano
- Gas Sensor
- Temperature Sensor
- PIR Motion Sensor
- Potentiometer & boya(buoy) as Water-Level Sensor
- LEDs
- Buzzers
- Resistors

System Features

- Gas detection and warning
- Ac controlling signal using Temperature monitoring
- Motion detection
- Water-level monitoring
- LED status indicators
- Audible warning system
- Sensor-based decision logic
